# Ветка port/26.3

Источник: только закоммиченное состояние `folia-1.21.11-audited` на коммите `759b427a0ff06c6f4bc03c73bbfaa97b110584e3`.
База upstream: `GrimAnticheat/Grim`, ветка `2.0`, коммит `8baa16f2b55d188eea81436aaa484d19b61085cd`.
Эта база уже содержит поддержку Minecraft 26.3 и PacketEvents `2.14.1+addb80e-SNAPSHOT`.

## Сохранение поведения

Все правила из [README-FORK.md](README-FORK.md) сохранены без упрощений. Единственное изменение кода выполнения относительно исходной ветки — адаптация передачи разрешённых Packet Criticals к новому ограничению протокола 26.3, описанная ниже. Незакоммиченные тесты, ресурсы и другие локальные файлы исходного рабочего каталога не входят в перенос.

Проверить изменения кода выполнения:

```powershell
git diff 759b427a0 HEAD -- common/src/main bukkit/src/main
```

Текущая версия артефакта: `2.3.75-26.3-port.1`. Настроенный toolchain сборки остаётся Java 21 с `--release 17`; для запуска Canvas/Folia 26.3 нужна Java 25. Старую Paper API в compileOnly не заменяем без необходимости: поддержка актуального протокола обеспечивается upstream и PacketEvents, а фактическую доступность Bukkit-событий проверяем запуском сервера.

## Сборка

В чистом checkout ветки `port/26.3`:

```powershell
.\gradlew.bat :common:build :bukkit:build -x spotlessApply -PbukkitOnly=true -PshadePE=true -Prelease=true --no-configuration-cache
```

Результат: `bukkit/build/libs/grimac-bukkit-2.3.75-26.3-port.1.jar` с включённым PacketEvents. Параметр `-x spotlessApply` исключает автоматическое изменение исходников; проверки форматирования и тесты остаются включены.

## Packet Criticals: port.1

Во время игровой проверки исходной сборки сервер кикал с `Invalid move player packet received`. В обработчике `ServerGamePacketListenerImpl.handleMovePlayer` Canvas 26.3 второй пакет позиции до `handleClientTickEnd` вызывает отключение, даже если Grim разрешил эту пару.

Для уже проверенных и разрешённых лимитером пакетов критов добавлена передача в порядке `CLIENT_TICK_END → исходное движение → CLIENT_TICK_END`. Исходный экземпляр отменяется, чтобы не передать движение дважды. Передача через `receivePacketSilently` происходит после декодера PacketEvents: синтетические границы не становятся дополнительными тиками предсказания или Timer в Grim. Координаты, флаги земли и коллизии сохраняются. Проверки опоры, свободного места сверху, неподвижности, высоты подъёма и частоты пары не ослаблены; отклонённые лимитером пакеты не пересылаются. На серверах до 26.3 остаётся прежний путь передачи.

Полная сборка `port.1`: **76 тестов, 0 ошибок**, включая порядок пакетов на 26.3, обычное движение перед/после пары, отсутствие пересылки сверх лимита и прежний путь на 1.21.11/26.1/26.2. Игровая проверка критического урона клиентом остаётся обязательной.

SHA-256 JAR `port.1`:

```text
a405a09121d8a489682484b4f744f4afd7e3b0f6287e5d4108744cb6b52dc556
```

Запуск без игроков не подтверждает игровую приёмку. Перед рабочим сервером остаётся проверить клиентом 26.3: обычное движение, транспорт, Strafe, Step/ReverseStep, Packet Criticals, добычу и ребрейк, кристаллы и плейсмент, перлы и выталкивание, взаимодействия внутри блоков, смену элитр, телепорты и переходы между регионами. Особое внимание — отсутствию ложных флагов при обычной игре. Проверка относится к указанной сборке Canvas; отдельный запуск на Folia 26.3 не выполнен.
