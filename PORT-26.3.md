# Ветка port/26.3

Источник: только закоммиченное состояние `folia-1.21.11-audited` на коммите `759b427a0ff06c6f4bc03c73bbfaa97b110584e3`.
База upstream: `GrimAnticheat/Grim`, ветка `2.0`, коммит `8baa16f2b55d188eea81436aaa484d19b61085cd`.
Эта база уже содержит поддержку Minecraft 26.3 и PacketEvents `2.14.1+addb80e-SNAPSHOT`.

## Сохранение поведения

Все правила из [README-FORK.md](README-FORK.md) сохранены без упрощений. Код выполнения в `common/src/main` и `bukkit/src/main` совпадает с исходной веткой. Незакоммиченные тесты, ресурсы и другие локальные файлы исходного рабочего каталога не входят в перенос.

Проверить отсутствие изменений правил:

```powershell
git diff 759b427a0 HEAD -- common/src/main bukkit/src/main
```

Отдельная версия артефакта: `2.3.75-26.3-port`. Настроенный toolchain сборки остаётся Java 21 с `--release 17`; для запуска Canvas/Folia 26.3 нужна Java 25. Старую Paper API в compileOnly не заменяем без необходимости: поддержка актуального протокола обеспечивается upstream и PacketEvents, а фактическую доступность Bukkit-событий проверяем запуском сервера.

## Сборка

В чистом checkout ветки `port/26.3`:

```powershell
.\gradlew.bat :common:build :bukkit:build -x spotlessApply -PbukkitOnly=true -PshadePE=true -Prelease=true --no-configuration-cache
```

Результат: `bukkit/build/libs/grimac-bukkit-2.3.75-26.3-port.jar` с включённым PacketEvents. Параметр `-x spotlessApply` исключает автоматическое изменение исходников; проверки форматирования и тесты остаются включены.

## Проверка

Чистое закоммиченное исходное состояние прошло полную сборку common/Bukkit, 59 тестов и проверку четырёх ServiceLoader-провайдеров.
На Canvas `26.3-991-HEAD@f52da32` с Java `25.0.2` проверена загрузка Grim и маппингов PacketEvents `V_26_3`, регистрация событий и планировщиков, и готовность сервера.

Финальный JAR `2.3.75-26.3-port` прошёл ту же полную сборку: **73 теста, 0 ошибок**, проверки форматирования и четырёх ServiceLoader-провайдеров. На указанном Canvas проверены запуск финального JAR, ответ `version GrimAC` и штатная остановка командой `stop`. Проверка обновлений Grim получила HTTP 403; загрузке и выключению плагина это не помешало.

SHA-256 финального JAR:

```text
ea66dd40f71e78494df68a49419f1210f99d4106fd7f09abcbfd739f5cacb581
```

Добавлены повторный прогон полного набора Packet Criticals для серверного протокола 26.3 и клиент 26.3 в проверку возвратных пакетов. Отдельные тесты EntitySpeed проверяют круговой лимит 60 км/ч, замедление в блоках, список транспорта и сохранение гравитации лодки при попытке зависнуть или подняться.

Запуск без игроков не подтверждает игровую приёмку. Перед рабочим сервером остаётся проверить клиентом 26.3: обычное движение, транспорт, Strafe, Step/ReverseStep, Packet Criticals, добычу и ребрейк, кристаллы и плейсмент, перлы и выталкивание, взаимодействия внутри блоков, смену элитр, телепорты и переходы между регионами. Особое внимание — отсутствию ложных флагов при обычной игре. Проверка относится к указанной сборке Canvas; отдельный запуск на Folia 26.3 не выполнен.
