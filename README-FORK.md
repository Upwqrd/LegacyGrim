# LegacyGrim

Целевая платформа: **Folia 1.21.11**. Ветка форка — [folia-1.21.11-audited](https://github.com/Upwqrd/LegacyGrim/tree/folia-1.21.11-audited).
[Все изменения относительно исходного Grim](https://github.com/GrimAnticheat/Grim/compare/8baa16f2b55d188eea81436aaa484d19b61085cd...Upwqrd:LegacyGrim:folia-1.21.11-audited).

| Патч | Фактическое правило |
|---|---|
| EntitySpeed | Дополнительное горизонтальное движение управляемого транспорта до **60 км/ч**: `60 / 72 = 0.833333…` блока за тик при 20 TPS. Диагональ не увеличивает предел. |
| Strafe | Допуск записанных профилей Meteor и второго протестированного клиента: низкие прыжки, повороты, сход со льда, углы блоков. В лаве разрешён горизонтальный Strafe. |
| Velocity | Разрешена отмена отдачи от ударов/взрывов и течения воды/лавы (`Liquids Horizontal/Vertical`: 0 или 1). |
| NoSlow | Разрешены движение и спринт без замедления от использования предметов. |
| Step / ReverseStep | Дополнительный подъём и спуск из step-height: по умолчанию 1 блок, максимум 2. |
| Перлы / выталкивание | Близкий бросок в твёрдую стену/потолок блокируется по направлению полёта. Из твёрдого блока игрок поднимается на том же X/Z максимум на 3 блока. |
| Действия внутри блоков | При пересечении тела с полным твёрдым блоком запрещены правый клик, использование предметов, установка блоков и кристаллов, взаимодействие с сущностями и запуск снарядов. Всю еду разрешено есть обеими руками. Вода/лава, сыпучие и неполные формы исключены. |
| InstantRebreak / Silent-добыча | Ребрейк разрешён для `0 <= hardness < obsidianHardness`. Для обсидиана и более твёрдых блоков требуется свежая добыча. Эндерсундук разрешён. |
| Packet Criticals | Стационарная пара: подъём Y на `0.0625…0.0626` и точный возврат; X/Z не меняются. |
| Лимит плейсмента | **2 принятые установки блоков на игрока за серверный тик**. Обе руки и AirPlace имеют общий бюджет; дверь/кровать стоит одну установку. |
| Свап и частота кристаллов | Кристалл должен быть в используемой сервером руке. В тик смены активного слота основной руки установка запрещена, со следующего серверного тика разрешена. `CrystalPlaceLimit: 6` — равномерные 6 CPS на игрока, обе руки вместе; 0 отключает лимит. |
| Кристаллы без Rotate | Установка и удар не требуют наведения; удар допускается до 4,5 блока от глаз до ближайшей точки хитбокса. |
| FastWeb / WrongBreak | STOP не создаёт предсказанный воздух в креативе. В выживании немгновенная паутина не получает исключение только из-за ранее мгновенно сломанного другого блока. |
| FakeFly | Ограничен показанный цикл «элитры → запуск полёта → нагрудник». |

Настройки: `step-height: 1.0` (0 отключает дополнительный шаг, максимум 2), `PearlPhasePrevention: true`, `PushOutOfBlocks: true`, `CrystalPlaceLimit: 6` (0 отключает лимит). Кристаллы: интервал 166,7 мс с поправкой на серверный тик, без накопления пачки; отмена возвращает интервал. Криты: 20 пар/с, запас 4 пары. Пороги NoSlow/Knockback/Explosion фиксированы кодом; SprintC исключён.

```powershell
git clone --branch folia-1.21.11-audited https://github.com/Upwqrd/LegacyGrim.git
cd LegacyGrim
.\gradlew.bat :common:build :bukkit:build -x spotlessApply -PbukkitOnly=true -PshadePE=true -Prelease=true --no-configuration-cache
```

JAR: `bukkit/build/libs/grimac-bukkit-2.3.75.jar`.
Сборка: toolchain Java 21, классы `--release 17`; запуск Folia 1.21.11 — Java 21. Linux: `./gradlew`. PacketEvents включён; ServiceLoader проверяется при сборке. Существующие config.yml/punishments.yml сохраняйте. Fabric и старые Spigot/Paper отдельно не проверены.
