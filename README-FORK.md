# LegacyGrim: описание форка для администратора

Ветка **port/26.3** сохраняет все закоммиченные правила исходной ветки ниже. Целевая среда этой ветки — **Canvas/Folia 26.3, Java 25**. Состав переноса, сборка и границы проверки описаны в [PORT-26.3.md](PORT-26.3.md).

Целевая платформа: **Folia 1.21.11**. Ветка форка — [folia-1.21.11-audited](https://github.com/Upwqrd/LegacyGrim/tree/folia-1.21.11-audited).
GitHub подтверждает, что Upwqrd/LegacyGrim является форком GrimAnticheat/Grim.

- [Все изменения относительно исходного Grim](https://github.com/GrimAnticheat/Grim/compare/8baa16f2b55d188eea81436aaa484d19b61085cd...Upwqrd:LegacyGrim:folia-1.21.11-audited).
- Зафиксированная база: `8baa16f2b55d188eea81436aaa484d19b61085cd`, ветка upstream `2.0`. Ссылка сравнения не зависит от последующих обновлений upstream.
- Ветка по умолчанию репозитория может показывать другой этап проекта: для этой сборки выбирайте указанную ветку форка.

## Все группы патчей

| Патч | Фактическое правило | Компоненты и зависимости |
|---|---|---|
| EntitySpeed | Дополнительное горизонтальное движение управляемого транспорта до **60 км/ч**: `60 / 72 = 0.833333…` блока за тик при 20 TPS. Диагональ не увеличивает предел. | EntitySpeedAllowance → PredictionEngine → uncertainty/коллизии; VectorData и учёт седла в PacketEntityRideable. Ванильные кандидаты не удаляются. |
| Strafe | Допуск записанных профилей Meteor и второго протестированного клиента: низкие прыжки, повороты, сход со льда, углы блоков. | StrafeAllowance, GrimPlayer, PredictionEngine; сброс при телепорте в MovementCheckRunner. Зависит от подтверждённой скорости предыдущего движения. |
| Velocity | Разрешена отмена отдачи от ударов и взрывов. Пороги KnockbackHandler/ExplosionHandler установлены в бесконечность. | Учёт импульсов остаётся частью физики. SetbackTeleportUtil не применяет ожидающие импульсы повторно при откате. Это сознательное послабление проверки Velocity. |
| NoSlow | Разрешены движение и спринт без замедления от использования предметов. | Порог NoSlow установлен в бесконечность, SprintC исключён из обработки. Slowness и Slow Falling продолжают участвовать в физике. |
| Step / ReverseStep | Дополнительный подъём и спуск из step-height: по умолчанию 1 блок, максимум 2. | Альтернативные коллизии в Collisions, оптимизация поиска в PredictionEngine, настройка GrimPlayer. Ванильный шаг сохраняется. ReverseStep отключён внутри паутины и при спуске в неё. |
| Перлы / выталкивание | Близкий бросок в твёрдую стену/потолок блокируется по направлению полёта. Из твёрдого блока игрок поднимается на том же X/Z максимум на 3 блока. | BlockPhaseProtection: взаимодействие до расхода предмета, запасной launch-обработчик, проверка после телепорта, реальные collision shapes и планировщик сущности. |
| Действия внутри блоков | При пересечении тела с полным твёрдым блоком запрещены правый клик, использование предметов, установка блоков и кристаллов, взаимодействие с сущностями и запуск снарядов. Всю еду разрешено есть обеими руками. Вода/лава, сыпучие и неполные формы исключены. | EmbeddedInteractionGuard: события обеих рук и прямые события установки; проверка только при действии, на текущем регионе, без загрузки чанков. Движение, атаки и добыча не меняются. Еда в руке не разрешает открывать блоки или взаимодействовать с сущностями. |
| InstantRebreak / Silent-добыча | Ребрейк разрешён для `0 <= hardness < obsidianHardness`. Для обсидиана и более твёрдых блоков требуется свежая добыча. Эндерсундук разрешён. | FastBreak, CheckManagerListener, серверный блок за предсказанием в CompensatedWorld, пакетно выбранный инструмент в CompensatedInventory. Новый прогресс не создаётся простой заменой блока; состояние сбрасывается между измерениями. |
| Packet Criticals | Стационарная пара: подъём Y на `0.0625…0.0626` и точный возврат; X/Z не меняются. | CheckManagerListener и флаг PacketStateData. Нужны опора, свободное место сверху и подходящее состояние игрока. Эти дополнительные пакеты обходят обработку движения/Timer в этом обработчике; обычные пакеты и атаки идут штатными путями. |
| Лимит плейсмента | **2 принятые установки блоков на игрока за серверный тик**. Обе руки и AirPlace имеют общий бюджет; дверь/кровать стоит одну установку. | BlockPlaceLimiter: HIGHEST/MONITOR, резервации незавершённых событий. Кристаллы, открытие сундуков и использование предметов не расходуют бюджет и этим лимитером не отменяются. |
| Свап кристаллов | Кристалл должен быть в используемой сервером руке. В тик смены активного слота основной руки установка запрещена, со следующего серверного тика разрешена. | CrystalSwapGuard: PlayerItemHeldEvent → cooldown → EntityPlaceEvent. Inventory swap без смены активного слота остаётся доступен; вторая рука не зависит от переключения основной. |
| Дальность удара по кристаллам | Допуск до 4,5 блока от глаз до хитбокса кристалла. Дальность атак по игрокам и другим сущностям не меняется. | Reach: немедленная отмена и отложенная проверка используют одинаковый допуск. Попадание в хитбокс и прочие штатные условия сохраняются; больший штатный допуск от атрибутов не уменьшается. |
| FastWeb / WrongBreak | STOP не создаёт предсказанный воздух в креативе. В выживании немгновенная паутина не получает исключение только из-за ранее мгновенно сломанного другого блока. | CheckManagerListener и WrongBreak; обычные START и допустимое продолжение после CANCEL сохраняются. |
| FakeFly | Ограничен показанный цикл «элитры → запуск полёта → нагрудник». | GlideSwapGuard: реальная экипировка, клики по chest-slot, вход/выход и серверный тик. Заранее надетые элитры и завершение полёта остаются доступны; возврат тех же элитр не должен навсегда блокировать взлёт. |

## Границы правил и взаимодействия

- EntitySpeed доступен первому пассажиру поддерживаемого, не вложенного в другой транспорт средства. Проверяются седло и управляющий предмет, где они требуются. Ламы, вагонетки и летающие сущности не добавлены в допуск.
- 60 км/ч — предел добавленного кандидата, а не принудительное ограничение законной скорости лодки на льду или внешнего импульса. При низком TPS скорость за реальную секунду меняется.
- Strafe/EntitySpeed сохраняют вертикальную составляющую обычной физики; исключения Step и Packet Criticals описаны отдельно. Паутина, жидкости, эффекты и коллизии продолжают иметь значение.
- Silent-добыча разрешена; мгновенная смена активного слота для кристаллов ограничена отдельно. Surround + AutoCrystal могут требовать inventory swap или ожидания независимо от блокового бюджета.
- Сервер не знает видимый слот интерфейса клиента. Silent с корректными серверными действиями и выдержанной паузой неотличим от разрешённого переключения.
- Ограничение свапа кристаллов действует только в тик смены активного слота. Это переход через границу серверного тика, а не гарантированные 50 мс: около границы ожидание может быть очень коротким. Движение и CLIENT_TICK_END его не сбрасывают. Silent с паузой до следующего серверного тика этим правилом не исключается.
- Жидкости, паутина и сыпучие блоки не вызывают указанное выталкивание. Твёрдая стена рядом с ними остаётся препятствием. Крыша, требующая подъёма более чем на 3 блока, оставляет игрока на месте по правилу сервера.
- Антибросок проверяет запас 0,85 блока по горизонтали от тела игрока и направление полёта перла. Запас сверху и снизу — 0,25 блока; общая дистанция трассировки — 2 блока от точки появления перла (0,1 блока ниже глаз), включая диагональные попадания в пол. Броски вплотную в пол блокируются; контакт с полом не запрещает горизонтальные броски или броски в небо. Стена за спиной сама по себе не запрещает бросок от неё.
- Bukkit-политики плейсмента, свапа и экипировки действуют и в креативе; отдельного исключения `grim.exempt` в этих обработчиках нет. Проверки ядра используют собственные штатные исключения.
- Отдельный VL за ограничения плейсмента/свапа/повторного твёрдого ребрейка не добавляется. Штатная защита от спама некорректными пакетами сохраняется.

## Конфигурация

Дополнительные настройки:

```yaml
step-height: 1.0
PearlPhasePrevention: true
PushOutOfBlocks: true
```

| Настройка | Поведение |
|---|---|
| step-height | Конечное число 0–2; выход за диапазон ограничивается, NaN/Infinity заменяются на 1. Ноль отключает дополнительный Step/ReverseStep, сохраняя ванильный шаг. |
| PearlPhasePrevention | Близкий антибросок и проверка попадания перла. Отключение не отключает отдельно включённый PushOutOfBlocks. |
| PushOutOfBlocks | Периодическое выталкивание. Отключение не отключает отдельно включённую защиту перлов. |

Остальные перечисленные правила заданы кодом и отдельного переключателя не имеют. Пороги `NoSlow.threshold`, `Knockback.threshold` и `Explosion.threshold` не восстанавливают исходное наказание: их заменяет бесконечный порог. SprintC не применяется. Защита InstantRebreak связана с FastBreak и его штатными исключениями.

Запрет взаимодействий внутри полных блоков действует независимо от PearlPhasePrevention/PushOutOfBlocks. Проверяется реальное пересечение с небольшим отступом от границ тела: стоять на полном блоке или касаться стены разрешено. Полный стеклянный блок и двойная плита считаются полными; обычные плиты, лестницы, заборы и люки не вызывают этот запрет. Spectator исключён, Creative подчиняется правилу. Отмена использует штатную синхронизацию Bukkit/Folia и не добавляет отдельный VL.

Не заменяйте рабочие config.yml/punishments.yml целиком ради установки. Три ключа добавлены в шаблоны en/ru; для остальных языков действуют те же программные значения по умолчанию.

## Потоки, события и совместимость

- Движение обрабатывается в существующем цикле Grim. Bukkit-коллизии и телепорты выполняются на регионе владельца сущности. Поиск выхода не загружает чанки и не читает чужой регион.
- Лимит плейсмента проверяется только при попытке установки. Выталкивание — отдельная задача раз в 5 тиков на игрока; при отключённых настройках проверка коллизий пропускается.
- Лимитер использует `Bukkit.getCurrentTick()`, на Folia это тик текущего региона. Незавершённые установки резервируются; финально отменённые/неразрешённые освобождают бюджет при следующей попытке. Остаток не переносится.
- Лишняя установка отменяется штатным Bukkit-событием; Folia выполняет rollback и синхронизацию. Собственной очереди установок нет.
- Другой плагин способен снять отмену после Grim. Абсолютная защита от такого переопределения не заявляется; порядок обработчиков нужно проверять на целевом наборе плагинов.
- Полный набор политик проверяется на Folia 1.21.11. Старые Spigot/Paper и Fabric не являются проверенными средами для всех этих изменений: Bukkit-часть использует Paper-события и современные API.

## Сборка

Используйте Gradle Wrapper и JDK, позволяющий выбрать настроенный toolchain Java 21. Собственные классы проекта компилируются с `--release 17`. Для запуска Folia учитывайте требования самой версии сервера.

```powershell
git clone --branch folia-1.21.11-audited https://github.com/Upwqrd/LegacyGrim.git
cd LegacyGrim
.\gradlew.bat :common:build :bukkit:build -x spotlessApply -PbukkitOnly=true -PshadePE=true -Prelease=true --no-configuration-cache
```

На Linux используется `./gradlew` с теми же аргументами. `-x spotlessApply` исключает автоматическое переписывание исходников; проверки форматирования, тесты, JavaDoc и JAR остаются включены. Без необязательного bukkitOnly стандартная конфигурация по-прежнему включает Fabric.

Самодостаточный плагин этой ветки: `bukkit/build/libs/grimac-bukkit-2.3.75-26.3-port.1.jar`. Sources/JavaDoc JAR не являются серверным плагином. Задача `:bukkit:verifyBundledServiceProviders` проверяет сохранность ServiceLoader-провайдеров после shading и входит в check.

Приведённая команда собирает Bukkit/Folia-вариант с включённым PacketEvents. Она не предназначена для сборки Lite или Fabric. Лицензия и исходная документация upstream сохранены.
